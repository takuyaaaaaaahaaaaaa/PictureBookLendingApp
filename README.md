# えほん台帳

えほん台帳は、保育園・幼稚園の絵本の貸出と返却を、共用iPadで管理するアプリです。お迎えの短い時間に、保護者や先生が迷わず操作できることを目指しています。

現在は個人で開発中です。設計の背景は[デザイン原則](docs/DESIGN_PRINCIPLES.md)にまとめています。

## 主な機能

- 絵本の貸出・返却と、貸出状況・返却期限の確認
- 絵本、利用者、組の登録・管理
- データのバックアップと復元

日常の貸出・返却はオフラインで利用できます。

## データの扱い

園児・保護者の名前と貸出記録は端末内に保存します。利用状況とクラッシュ診断の送信は、それぞれ管理者の同意に基づきます。書誌情報を検索する際は、ISBN・書名・著者名を楽天ブックスAPIへ送信します。詳しくは[プライバシーポリシー](docs/privacy-policy.md)をご覧ください。

バックアップには名前や貸出記録が含まれます。公開IssueやPRに、実際の利用データやバックアップを添付しないでください。

## 開発環境で試す

対応するXcodeと、iOS / iPadOS 26以降のシミュレータまたは端末が必要です。

1. [Xcodeプロジェクト](PictureBookLendingAdminApp/PictureBookLendingAdmin.xcodeproj)を開き、`PictureBookLendingAdmin` スキームを選びます。
2. `PictureBookLendingAdminApp/Secrets.xcconfig.template` を同じ場所に `Secrets.xcconfig` としてコピーします。楽天ブックスの書誌検索を試す場合は、楽天ウェブサービスのアプリIDとアクセスキーを設定します。`Secrets.xcconfig` はGitの管理対象外です。
3. シミュレータまたは端末を選んで実行します。

Firebase用の `GoogleService-Info.plist` もリポジトリには含めていません。このファイルがない環境では、利用状況とクラッシュ診断の送信は設定されません。

## 開発・公開方針

提案や不具合報告はIssueで受け付けますが、返信時期やPRの採用は保証していません。実際の園児・保護者の情報は投稿しないでください。

現時点でライセンスは未設定です。ソースコードは公開していますが、利用・改変・再配布を許可するOSSライセンスはまだ付けていません。
