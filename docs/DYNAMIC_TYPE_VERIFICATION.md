# 貸出・返却の Dynamic Type 検証（2026-10-14）

## 対象と方針

main `7bbee1bcbc64a811af99cbb0504de5676f8b82c0` を起点に、貸出タブの本棚／図書リスト、利用者選択、枠確認、返却の家庭枠を確認した。

- 既存の semantic font、`ScaledMetric`、本棚と利用者カードの列数調整を再利用する。
- `.xxxLarge` 以上では図書リスト・貸出確認の表紙と書名・家庭枠を縦方向に配置する。`AnyLayout` で同じ子ビューと操作を保持する。
- 本棚／グリッドの書名は標準サイズより大きければ行数を制限しない。標準の2行表示は維持する。
- 組チップが収まらないときはメニューに畳み、組の選択・解除操作を残す。
- 文字サイズの上限・一律の既定サイズ変更・独自の拡大設定は追加しない。既存の「大きく表示」はそのまま。
- `lendingControlsBar` の iOS 26 iPhone 回避策・iPad/27以降の `safeAreaBar`、MARKETING_VERSION 1.1を維持する。

## 未確認・制約

- 実機、実際のSplit View、設定アプリの「アプリごとの設定」経由、検索文字入力後の保持、組メニューの実操作は未確認。システム文字サイズのライブ変更は `simctl ui … content_size` で確認した。
- iPhoneのUIツリーは `No translation object returned for simulator` となり、アプリ再起動とテスト実行後も改善しなかった。画像確認・テスト成功を、操作完了の代わりには扱わない。
- iPadの初回UI取得は事前チェックで失敗し、テスト実行後に回復した。事前チェック内部の自動修復はsim-useデーモンを停止するため、以後は全デーモンの自動修復を再実行していない。
- 管理用の旧 `LoanConfirmationView` 等、今回の主要導線から外れる画面は変更していない。
- 既存のカメラorientation非推奨警告は残る。Cloudの27.1 iPad runtime問題は本変更の対象外で、Cloud設定変更・追加ビルド起動は行っていない。
