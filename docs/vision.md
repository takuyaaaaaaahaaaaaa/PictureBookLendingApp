# えほん台帳のビジョン・ミッション・バリュー

AIエージェントと開発者が、何を作るか・どちらを選ぶかで迷ったときの判断基準です。

## ビジョン

毎日のちょっとの手間を、ゼロに。

## ミッション

1. 保育園の絵本の貸し借りの手間をゼロにする。
2. 全世界の保育園に届ける。

## バリュー

迷ったら上を優先する。

1. 安心を削らない。
2. 説明なしで使える。
3. 手間を足さない。
4. 小さく出して、測って確かめる。
5. 遊び心で、技術に挑戦する。

## 戦略

### 最初に届ける相手

- 紙で絵本の貸出を管理していて、保護者が送迎時に自分で借りる、50人前後の認可保育園。
- iPadがすでにある園を優先する。ない園も断らない。
- 並行して、今使っている園で効果を測る。

### やらないこと

- 保護者のスマホ対応
- クラウド同期・アカウント登録
- 課金

大きな新機能は禁止しない（挑戦と実験の場）。ただし作る前に、効果をどう測るかを決める。

### 保留・低優先

- 顔認証: 実装は保留。調査だけ並行して進める。端末内処理のみで、顔データを外に出さない前提。
- 多言語対応: 低優先。ログ設計の後に進める。

### 進める順番

1. ログ設計: 貸出・返却にかかる時間と、表紙検索の未ヒット率を端末内で記録する。個人情報や画像は記録しない。
2. 表紙検索の改善（Issue #316）の再開
3. 顔認証の調査（並行）
4. 普及: 似た園への届け方と、反応の集め方を決める
5. 多言語対応（低優先）
6. List から Collection への置き換え（低優先。ログで遅い画面が分かれば優先度を上げる）
