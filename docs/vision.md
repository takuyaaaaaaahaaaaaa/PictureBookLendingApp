# えほん台帳のビジョン・ミッション・バリュー

AIエージェントと開発者が、何を作るか・どちらを選ぶかで迷ったときの判断基準です。

## ビジョン

毎日のちょっとの手間を、ゼロに。

## ミッション

1. 保育園の絵本の貸し借りの手間をゼロにする。
2. 全世界の保育園に届ける。

## バリュー(迷ったら上から優先)

1. 安心を削らない。速くするために、子どもや家族のデータを危険にさらさない。データは端末の外に出さないのが基本。
2. 説明なしで使える。初めての人でも迷わずに使える。
3. 手間を足さない。機能を足すのは、増える操作より減る手間の方が大きいときだけ。
4. 測ってから言う。効果は数字で確かめ、測れていないものは「未確認」と書く。
5. 小さく続ける。限られた時間で回せる大きさに切って、止めずに届ける。
