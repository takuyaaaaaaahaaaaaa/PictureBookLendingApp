# 2026-10-02 UIレビュー用スクリーンショット

専用iPadOS 26.5シミュレータとDEBUG UIカタログの実画面。画像は保存後に目視確認済み。Xcode Previewのレンダリングではありません。
サンプルまたは空の端末のみで、本番の利用者・貸出記録・APIキー・通信ログを含みません。Privacy画面はFirebase設定ファイルなしでの表示確認です。

- colors-*：色・表面の見え方を確認。周辺UIには後続の余白修正も含むため、色PR単体の全画面差分とは扱いません。
- color-catalog：ライト/ダークのトークン見本。
- wide-*：実幅で切替える操作群、通常文字/AX3。
- scroll-*：同じ「見本14」を基準に1024ptから375ptへ戻した結果。
- loans-*：375pt/AX3の行内折返し変更前後。Beforeは端末のみ、AfterはDeviceHub枠を含みます。
- privacy-*：初期両方オフ、診断のみ許可。実SDK送信の証拠ではありません。

画像は変更群の統合状態を示すものを含みます。各PRの差分と未検証事項はPR本文を参照してください。
