# 幅変更時の回帰確認 (#231 / #232 / #234)

## 確認環境

DEBUG の UIカタログ →「幅と状態を確認」で 375 / 744 / 1024pt を切り替える。
5.4 / 7.6 / 12.9インチはケース名であり、固定point幅による代理条件。Duoの実機開閉・ヒンジ・OSからのサイズ提案そのものを再現するものではない。
見本データのみ、画像通信・保存・貸出/返却の確定は行わない。

`AdaptiveLayoutPreview.swift` には図書一覧・貸出一覧・利用者一覧 × 3サイズ × 標準 / `.accessibility3` の18 Previewがある。

## 状態の所有と変更範囲

- 貸出一覧の検索・かな・並び順・表示形式、貸出シートの選択は既存Containerの `@State` に残す。幅をキーにした `.id` や別NavigationStackへの差替えは行わない。
- 返却画面の `navigationPath` と検索、利用者フォームの入力は既存Containerが保持する。幅変化を契機に初期化する処理を追加しない。
- 図書のgrid/shelfは本IDに結びついた `scrollPosition` を保持する。画面のピクセル位置は列数で変わり、同じ本を基準に再配置する。
- リストのネイティブListはそのまま保持する。かな変更と貸出完了後の明示的な先頭戻しは従来どおり。
- 見本本のUUIDはStateに一度生成し、検索や幅変更で再生成しない。

## 手動回帰手順

| 対象 | 操作 | 合格条件 |
| --- | --- | --- |
| 図書一覧 | 棚/グリッド/リストを選び、375→744→1024→375pt | 選択した表示形式と並び順が残る。操作が画面外に消えない |
| 図書検索 | 「見本 1」等を入力して幅を往復 | 検索テキストと結果が残る |
| 棚・グリッド | 中ほどへスクロールし、先頭付近の本を覚えて幅を往復 | 同じ本の付近を表示し、先頭に飛ばない |
| 利用者見本 | 行を開き入力見本に文字を入れて幅を往復 | 戻されず、入力文字が残る（保存なし） |
| 貸出シート | 実運用ContainerをメモリRepositoryで開き、借用者選択中にウインドウサイズ変更 | 選択・検索・シートが残る。確定はしない |
| 利用者登録 | 実運用ContainerをメモリRepositoryで開き、名前を入力中にサイズ変更 | 入力と選択中の組が残る。登録はしない |
| 返却詳細 | メモリRepositoryのサンプルで詳細を開きサイズ変更 | navigationPathが残る。既存15秒の無操作復帰とは区別する |
| 全画面 | AX3で3幅を往復 | 主操作とラベルが重ならず、縦スクロールで到達可能 |

幅切替ホストの入力見本はNavigation/入力の寿命確認用であり、本番Containerの入力回帰を完了した証拠とはしない。実機・本番データを使う検証は不要。実運用Containerの回帰はメモリRepositoryか専用の使い捨てデータで行う。
