## 再現手順

Debugビルドのカタログ→「本番Containerの状態を確認（メモリ内の見本）」を開く。画面メニューで対象を選び、入力・選択・スクロール後に幅ボタンを375→744→1024→375の順で押す。実効幅表示を必ず確認する。画面メニューの切替は別Containerへ移るため状態リセットを許容する。貸出・返却経路の通常の無操作タイムアウト（15秒）内に操作する。

## 限界

親frameの幅変更の確認。実Duoの開閉、OSのウィンドウリサイズ、scene再生成、実際のsheet提示状態は未確認。BorrowSheetはContainerの直接埋め込み。Pixel offsetの完全一致、全Dynamic Type条件、VoiceOver全操作の合格を示すものではない。

最終統合ソースの全214テスト成功（失敗・skip 0）。簡素化確認と独立レビューで設定への逸脱と実効幅表示の指摘を解消。本検証による状態保持実装の追加修正は不要だった。
