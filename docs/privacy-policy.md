# えほん台帳 プライバシーポリシー

**1. 端末内に保存する情報**
利用者（園児・保護者）の名前、絵本、貸出・返却の記録は、お使いの端末内に保存します。
これらの業務データを開発者のサーバーへ送信することはありません。
不要な情報は管理画面や「端末初期化」から削除できます。書き出したバックアップは、保存先で別途管理・削除してください。

**2. 任意で送信する情報と同意**
アプリの改善のため、管理者が「設定 → プライバシーとデータ送信」で同意した項目のみを送信します。
利用状況とクラッシュ診断は別々に選べ、初めはどちらも送信しません。拒否したまま貸出・返却などの機能を利用できます。

- **利用状況**：操作の種類・所要時間・件数、アプリの利用状況、アプリインスタンスを区別する広告用ではないID。Google LLCのFirebase Analyticsを使い、使いやすさを改善するために保存・集計します。
- **クラッシュ診断**：機種・OS・アプリのバージョン、異常終了時の処理の記録、診断用ID。Google LLCのFirebase Crashlyticsを使い、不具合調査と品質改善に利用します。初回に自動送信を許可した後は、クラッシュ情報を端末に記録し、通常は次回の起動時に自動送信します。同意前を含めて端末に保存済みの診断も送信対象になります。

利用者の名前、絵本の題名、検索した文字列、貸出記録そのものは分析・診断へ送りません。同意しても送信対象にはなりません。
広告用の識別子は使用せず、情報を広告や他社アプリをまたぐトラッキングに利用したり販売したりしません。

**3. 同意の取り消し**
同じ設定画面でいつでも項目ごとにオフにできます。
利用状況は新たな収集を停止し、端末ローカルの分析データとアプリインスタンスIDをリセットします。サーバーへ送信済みの情報を削除する操作ではありません。
クラッシュ診断のオフは次回起動から反映されます。未送信情報は端末に残る場合があり、後で再び許可すると、保存済みの情報も送信対象になります。
送信済み・送信を開始済みの情報を端末の設定から取り消すことはできません。

**4. 保持と削除**
送信したクラッシュ情報はFirebaseの方針に従って90日保持した後、稼働系とバックアップから削除が始まります。90日目に削除が完了するという意味ではありません。
利用状況の保持はGoogle Analyticsの設定とデータ種別によって異なり、集計レポートなどには別の扱いがあります。
詳細は [Firebaseのプライバシー方針](https://firebase.google.com/support/privacy) と [Google Analyticsのデータ保持](https://support.google.com/analytics/answer/7667196) を参照してください。
送信済み情報の削除に関するお問い合わせは下記へお願いします。名前や広告IDを送信していないため、個人を特定して削除できない場合があります。

**5. 絵本情報の取得**
図書登録時に書誌情報を検索するときは、ISBN・書名・著者名を楽天ブックスAPI（楽天グループ株式会社）へ送信して書誌情報と表紙画像を取得します。
利用者の情報は送信しません。これは登録操作に必要な通信で、分析・診断の送信選択とは別です。
